## New features in Service Manager 2022

Service Manager 2022 doesn't introduce any new features. For information about issues fixed in Service Manager 2022, see the [release notes](https://learn.microsoft.com/system-center/scsm/release-notes-sm?view=sc-sm-2022&preserve-view=true).

## New features in Service Manager 2022 UR4

The following sections introduce the new features or feature updates supported in Service Manager 2022 Update Rollup 4 (UR4).

For problems fixed in UR4 and the installation instructions for UR4, see the [KB article](https://support.microsoft.com/kb/5120167).

### Support for MSOLEDBSQL 19

Service Manager 2022 UR1 supports MSOLEDBSQL 19. [Learn more](https://learn.microsoft.com/system-center/scsm/sm-sql-reqs?view=sc-sm-2022&preserve-view=true).

### Microsoft Graph API support for the Exchange Connector

Service Manager 2022 UR4 introduces Microsoft Graph API support for the Exchange Connector, enabling Exchange Online integration without relying on Exchange Web Services (EWS). [Learn more](https://www.microsoft.com/download/details.aspx?id=101579).

### Microsoft Graph API support for outgoing email notifications

Service Manager 2022 UR4 introduces Microsoft Graph API authentication support for outgoing email notifications through Exchange Online. [Learn more](https://www.microsoft.com/download/details.aspx?id=101579).
